# Gmod Addons

This repository contains various Garry's Mod addons. The `rankup` addon provides a lightweight leveling system for DarkRP servers.

## RankUp Features
- Gain experience from salaries and police arrests
- Automatic level ups with health and speed bonuses
- HUD element displaying your current XP and level
- Derma menu accessible with `!rang` showing your progress
- **New:** water buff that grants massive boosts when swimming
